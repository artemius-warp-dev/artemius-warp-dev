### Hi, I'm Artem

Backend engineer with 9 years of experience, mostly on the **BEAM** (Erlang/OTP, Elixir)
and in **Go**. I've built backend systems for insurance, telecom, e-commerce and now
fintech. Based in Tashkent, Uzbekistan.

- **Now:** Erlang developer at [EXANTE](https://exante.eu), a multi-asset broker.
- **Fun Box (2022–2023):** Elixir on MobileID, an authentication platform for Russian
  mobile operators. I worked on the OpenID proxy to the operators' identity gateway, and
  moved parts of the Elixir monolith to Go microservices.
- **Sreda Solutions (2017–2021):** the Simble insurance app. I led a team of 4 on the
  car-insurance integration, built Broadway pipelines over AWS SQS, and wrote Elixir
  services that drive Python through Erlang ports.
- **Andersen, Smart Soft (2023–2025):** full-stack work on e-commerce order processing
  (GraphQL, MongoDB, Vue 3 migration) and a Go/Vue payroll integration MVP.

MSc in Software Engineering, Peter the Great St. Petersburg Polytechnic University.
